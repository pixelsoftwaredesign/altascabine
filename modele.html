Un modèle de cabine :
matériel + logiciel

Chaque cabine est pensée comme un système : un cerveau, des actionneurs, des capteurs, et une couche logicielle qui s'adapte au matériel installé. Deux architectures, un seul serment : ce qui n'existe pas physiquement ne s'exécute pas.

HARDWARE FIRMWARE EDGE (Pi) APP & WEB

Vue d'ensemble du modèle

MATÉRIEL — salle + contrôleur

🛡️ Contrôleur central (ESP32 / Pi / Arduino)

🔋 Alimentation + coupure d'urgence secteur

⚙️ Gâche électrique · relais 16 A · voyant

👂 Reed porte · PIR présence · bouton urgence 36

💡 LED RGBW · clim 2,7 kW · capteur CO₂ / AC

📷 Caméra (modèle Pi) · écran / tablette HMI

LOGICIEL — cerveau de bord → cloud

🔩 Firmware C++ : commandes porte, scan, urgence

🍓 cabin-hub Node : broker MQTT local + API + WS

🤖 App Android : détection du hub, télécommande

🌍 Kiosque web : session, QR, éclairage, télémétrie

📊 Dashboards usine/commercial : temps réel

☁️ Cloudflare Pages : orchestration & identités

cabin-hub (edge Pi)

Kotlin
App Android AtlasCabine
